# Background assets

Drop static hero / hub backgrounds here. The app loads them from `/backgrounds/…`.

## Hero (landing page)

| File | Used by |
|------|---------|
| `hero-bull.jpg` | `HeroBackdrop` — main landing visual (e.g. bull artwork) |
| `hero-bull.webp` | optional lighter variant |

## PegKeeper hub orbit

| File | Used by |
|------|---------|
| `hub/default.jpg` | `HubBackdrop` — behind partner orbit |
| `hub/*.jpg` / `hub/*.webp` | swap `default.jpg` or extend `HubBackdrop` |

## Videos (optional)

Place loop files in `/public/videos/` (see `videos/README.md`).
